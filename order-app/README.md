# 🍱 제육이다 — 단체 도시락 주문 접수 앱

손님은 **링크 하나로 주문서 작성** → **구글 시트에 자동 저장** → 사장님 휴대폰으로 **텔레그램 푸시 + Gmail 알림**.
서버·호스팅 비용 0원 (Google Apps Script 무료 한도 내).

| 파일 | 역할 |
|---|---|
| `Code.gs` | 주문 저장, 입력 검증, 알림 발송 (설정값은 맨 위 `CONFIG`) |
| `Index.html` | 손님용 주문서 화면 (모바일 최적화, 여러 날짜 한 번에 주문) |

## 설치 체크리스트 (약 20~30분)

### 1. 시트 + 스크립트 만들기
- [ ] 구글 드라이브 → 새 **Google 스프레드시트** 생성 (이름 예: `단체주문`)
- [ ] 메뉴 **확장 프로그램 → Apps Script**
- [ ] 기본 `Code.gs` 내용을 지우고 이 폴더의 `Code.gs` 붙여넣기
- [ ] 왼쪽 `+` → **HTML** → 이름 `Index` → `Index.html` 내용 붙여넣기
- [ ] `Code.gs` 맨 위 `CONFIG`에서 메뉴·가격·할인·홍보문구 확인 (제육이다 기준으로 입력돼 있음) → 저장

### 2. 텔레그램 알림 (즉시 푸시, 권장)
- [ ] 텔레그램에서 `@BotFather` → `/newbot` → 봇 이름 정하기 → **토큰** 복사
- [ ] Apps Script 왼쪽 ⚙️ **프로젝트 설정 → 스크립트 속성** → `TELEGRAM_TOKEN` = 토큰
- [ ] 방금 만든 봇과 대화방 열고 아무 메시지 전송
- [ ] 편집기에서 함수 `setupFindTelegramChatId` 선택 → ▶ 실행 → 실행 로그의 숫자 복사
- [ ] 스크립트 속성에 `TELEGRAM_CHAT_ID` = 그 숫자
- (가족·직원도 받게 하려면 텔레그램 그룹에 봇 초대 → 그룹 chat_id 사용)

### 3. 테스트
- [ ] 함수 `setupTestNotify` 실행 → 권한 승인 (“확인되지 않은 앱” 화면 → 고급 → 이동)
- [ ] 텔레그램 + Gmail 로 테스트 알림 도착 확인, 시트에 `주문` 탭 생성 확인

### 4. 배포 (손님용 링크 만들기)
- [ ] 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**
- [ ] 실행 계정: **나** / 액세스 권한: **모든 사용자**
- [ ] 생성된 `https://script.google.com/macros/s/…/exec` 링크를 손님에게 전달
  - 카카오톡 채널 자동응답, 인스타 프로필, 네이버 플레이스, 명함 QR 에 걸어두기
- [ ] **코드를 고친 뒤에는** 배포 → 배포 관리 → ✏️ → 버전 `새 버전` 으로 다시 배포해야 반영됨

## 운영 방법
- 시트 `상태` 칸: `접수 → 확정 → 완료 / 취소` 드롭다운으로 관리
- `메모` 칸: 결제·예약금 환불 여부 등 기록
- 여러 날짜 주문은 **날짜별로 한 줄씩** 저장됨 (접수번호 끝 `-1`, `-2`)

## 알아둘 점
| 항목 | 내용 |
|---|---|
| 무료 한도 | Gmail 발송 하루 100통(일반 계정), 웹앱 호출은 소규모 가게엔 사실상 무제한 |
| 개인정보 | 주문서에 수집·이용 동의 체크 포함. 보유기간(1년) 지나면 시트에서 행 삭제 |
| 결제 | 앱은 접수만 함. 카드결제·예약금 환불은 기존 방식(전화/단말기)으로 처리 |
| 링크 상단 문구 | 구글 웹앱은 “Google 사용자가 아닌 다른 사용자가 만든 앱” 안내 띠가 표시됨 (제거 불가) |
