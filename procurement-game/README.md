# 우리 마을 조달청 · 전국 조달 원정대

공공조달 게임 공모전 출품용 **오프라인 단일 HTML 게임**. 기존 「우리 마을 조달청」(5개 마을)의 블록 마을 엔진·캐릭터를 유지하며 전국 17개 시·도 캠페인으로 확장.

## 제출물

| 파일 | 내용 | 상태 |
|---|---|---|
| `dist/우리마을조달청_전국조달원정대.html` | 제출용 게임 (약 0.5MB, 인터넷 불필요) | 완료 |
| `video/demo_60s.mp4` | 시연영상 1920×1080 · 60초 · H.264 (자동 플레이 녹화) | 완료 · 공고문 규격 대조 필요 |
| `dist/woorimaeul-jodal.html` | 위 게임과 동일 (영문 파일명) | 완료 |

| 게임 장치 | 연결한 실제 조달 개념 |

| 현장 조사 | 수요 조사 · 구매 규격 |

| 제품 비교 화면 | 나라장터에서 가격·규격 비교 |


## 지역 1곳의 흐름 (약 35~45초)

| 단계 | 플레이어 행동 | 점수 반영 |
|---|---|---|
| 1 현장 조사 | 장면 속 주민 클릭 → 대사·조사 노트 | 주민 만족도(조사 인원) |
| 2 예산 배분 | 안전시설 / 편의시설 / 유지관리 중 선택 → 구매 한도·예비비 결정 | 만족도(우선순위 일치), 유지관리 |
| 3 제품 비교 | A 경제형 / B 균형형 / C 고급형: 가격·성능·연 유지비·납기·5년 총비용 | 제품 적합성, 예산 운영, 유지관리 |
| 4 긴급 상황 | 이벤트 D-day vs 납기 확인, 예비비로 긴급 배송 선택 가능 | 납기·위기 대응 |
| 5 지역 회복 | 공급 차량 도착 → 하역 → 조립 → 작동 → 주민 반응 (건너뛰기 가능) | — |

점수: 주민 만족도 30 · 예산 운영 20 · 제품 적합성 25 · 납기·위기 대응 15 · 유지관리 효율 10 → 85+ ★★★ / 65+ ★★ / 그 외 ★.
밸런스 점검(`node tools/balance.js`): 17개 지역 모두 최고점이 '최저가 A형'이 아님. 대구·강원·전남·제주는 고가 C형(재고 보유) 또는 긴급 배송이 유리.

## 기존 버전 대비 수정 사항

| 기존 문제 | 조치 |
|---|---|
| 캔버스가 화면 비율대로 늘어나 캐릭터가 찌그러짐 | 균일 배율 카메라로 변경 |
| 태양광 패널이 지붕 속으로 묻힘 | 설치물은 지붕 최상단 높이(3.05) 위에 고정, 그리기 순서를 지붕보다 뒤로 지정 |
| 누워 있는 사람이 사람처럼 안 보임 | 사용자 제공 '누운 이장님' 이미지 사용(경북), 배경 주민은 머리·몸통·팔다리 블록 인형 |
| 말풍선이 캐릭터를 가림 | 머리 위 배치 + 이웃 캐릭터 얼굴을 피해 옆으로 이동, 긴 대사 2줄 |
| 6MB 용량 | 이미지 WebP 재압축으로 약 0.5MB |

캐릭터: 제육황제(원정대장·조사), 부이(조달·예산), 반딧대왕(설치), 다랑이(길 안내), 영등할망(기상 특보, 패널 초상화만), 주민: 마을이장·몽돌이·소랑이·소라대감·자청비. 영등할망은 배경과 색이 비슷해 누끼 품질이 낮아 장면에는 넣지 않음.

## 개발 구조

```
src/index.html  화면 뼈대         src/style.css  스타일
src/data.js     17개 지역 데이터·점수 규칙
src/engine.js   아이소메트릭 블록 렌더러(기존 엔진 계승)
src/scenes.js   지역별 장면·시설 조립   src/game.js  진행·지도·저장   src/demo.js  시연 자동재생
assets/*.webp   캐릭터 이미지
tools/build.py      → dist/ 단일 HTML 생성
tools/balance.js    선택 조합별 점수 점검
tools/playtest.js   17개 지역 실제 클릭 플레이 테스트(콘솔 오류 검사)
tools/record.js     ?demo 모드 1920×1080 녹화
```

```bash
python3 tools/build.py                      # 빌드
node tools/balance.js                       # 밸런스
node tools/playtest.js shots 1440 900       # 전체 플레이 테스트
node tools/record.js video && ffmpeg -ss 0.6 -i video/*.webm -t 60 -c:v libx264 -crf 20 -pix_fmt yuv420p video/demo_60s.mp4
```

## 시연영상 60초 구성 (`게임.html?demo` 로 재현 가능)

| 구간 | 화면 |
|---|---|
| 0~7초 | 타이틀(원정대 4인) → 전국 지도 |
| 7~17초 | 제주 도착, 주민 3명 조사(말풍선) |
| 17~28초 | 예산 배분 → 제품 A·B·C 비교 |
| 28~39초 | 태풍 D-4 긴급 상황 → 공급 차량 출발 |
| 39~50초 | 지붕 태양광·배터리 설치, 정전 속 불 켜짐, 결과 ★★★ |
| 50~60초 | 제주가 밝아진 전국 지도 → 핵심 메시지 |

※ 영상은 실제 플레이 장면만 사용(가상 완료 연출 없음). 17곳 완주는 `tools/playtest.js`로 검증.
