# MY LIFE v4.0
모바일 설치형 정적 웹앱. 별도 백엔드, 계정, 사용자 DB 없음.

## 배포
새 공개 GitHub 저장소 `my-life`를 생성한 후 이 폴더의 파일을 루트에 모두 업로드합니다. Settings → Pages → Deploy from a branch → main / (root) → Save. HTTPS 주소가 표시되면 접속 확인. 다른 정적 HTTPS 호스팅도 가능.

## 설치 및 저장
아이폰 Safari 공유 → 홈 화면에 추가. 안드로이드 Chrome 메뉴 → 앱 설치/홈 화면에 추가. 할 일 및 텍스트 문서만 localStorage에 저장. 원본 사진은 분석 후 보관하지 않음. 브라우저/기기 간 자동 동기화 없음. 브라우저 데이터 삭제/기기 분실 등에 대비해 설정에서 JSON 백업. 설치 후 앱 화면 및 문자 기반 규칙 분석/일정/보관함은 오프라인 사용 가능. 첫 OCR 엔진/모델 다운로드는 인터넷 필요; 음성 인식은 브라우저 서비스 지원 및 동의 필요; Gemini는 선택적 외부 API, 사용자가 키 입력 및 전송 동의 필요. API 키는 세션 메모리에만 유지.

index.html 직접 열면 기본 기능 확인 가능. 설치/서비스워커는 HTTPS 또는 localhost 필요.
