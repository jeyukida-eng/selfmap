오늘의 날씨 풍경

같은 제주 풍경에 실제 현재 날씨를 반영합니다. 기본 지역은 제주시이며, 직접 선택하거나 위치 사용에 동의할 수 있어요. 선택 지역의 좌표는 날씨 제공사 Open-Meteo에 전송됩니다. 위치 사용 시 약 10km 단위로 반올림한 좌표만 사용합니다.

날씨 데이터: Open-Meteo (비상업용).
공모전 시연 및 그림 확인용 미리보기는 실제 날씨와 구분됩니다.

기한 전 자동 알림

알림 시점을 선택하세요. 앱 실행 중 자동 확인하며, 휴대폰 캘린더에 가져온 일정은 앱 종료 후에도 캘린더 설정에 따라 알림을 받을 수 있습니다.

생성형 AI 연결 (선택)

기본 모드는 API 키 없이 작동합니다. Gemini를 연결하면 복잡한 문장을 생성형 AI로 요약할 수 있습니다. 연결 시 입력 텍스트(일부 개인정보 자동 가림)가 Google로 전송됩니다. 민감정보는 직접 제거하세요. 사진은 로컬 OCR 후 텍스트만 전달됩니다.

개인정보 및 저장

저장 데이터는 현재 기기의 브라우저 저장소에만 남으며 별도의 회원가입이나 데이터 서버가 없습니다. 브라우저 데이터를 삭제하면 사라질 수 있습니다. OCR 엔진 다운로드에 인터넷이 필요할 수 있으며 사진은 기기에서 인식합니다. 음성 인식은 동의 후 브라우저의 외부 서비스를 이용할 수 있습니다. 생성형 AI는 선택 기능이며 동의 시 텍스트가 외부로 전송됩니다.
